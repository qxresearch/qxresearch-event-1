# 🔐 Password Generator (Tkinter)

A customizable password generator built using Python and Tkinter with enhanced UI, strength analysis, and clipboard support.

---

## ✨ Features

- Generate secure random passwords
- Customizable options:
  - Uppercase letters
  - Lowercase letters
  - Digits
  - Symbols
- Password strength indicator (Weak / Medium / Strong)
- Copy password to clipboard
- Simple and clean GUI
